# User Flow

## 1. 맛집 조회 흐름

1. 사용자는 메인 페이지에 접속한다.
2. 사용자는 일본 지도에서 관광지를 선택한다.
3. 선택한 관광지를 중심으로 지도가 확대된다.
4. 사용자는 해당 관광지 주변의 맛집 마커를 확인한다.
5. 사용자는 맛집 마커를 클릭한다.
6. 사용자는 맛집 상세 정보를 확인한다.

---

## 2. 리뷰 작성 흐름

1. 사용자는 로그인을 한다.
2. 사용자는 맛집 상세 페이지로 이동한다.
3. 시스템은 현재 사용자가 해당 맛집에 이미 리뷰를 작성했는지 확인한다.
4. 작성 이력이 없으면 리뷰 작성 폼이 바로 표시된다.
5. 사용자는 평점과 리뷰 내용을 입력하고 저장한다.
6. 저장된 리뷰가 맛집 상세 페이지에 표시된다.
7. 작성 이력이 있으면 작성 폼 대신 본인 리뷰에 수정/삭제 버튼이 표시되어, 중복 작성을 시도할 수 없다.

---

## 3. 리뷰 수정/삭제 흐름

1. 사용자는 로그인을 한다.
2. 사용자는 자신이 작성한 리뷰를 확인한다.
3. 사용자는 리뷰 수정 또는 삭제 버튼을 클릭한다.
4. 시스템은 현재 로그인한 사용자와 리뷰 작성자가 같은지 확인한다.
5. 작성자가 같으면 수정 또는 삭제를 수행한다.
6. 작성자가 다르면 권한 없음 메시지를 표시한다.
